## The change

- **PR:** #184 — the labeled fit-family triple joins the §5.D share artifact,
  open at t3 and a seal hatch with the value absent below it. New §5.D v0.61

## Who reviewed

**One author. One adversarial cross-read, same model family — which is not a
cross-model read, and this file will not let the distinction blur.** The read
was run against the **uncommitted** diff, before the PR existed. Every prior
review in this chain ran after the merge, and the one that mattered found a
defect already live in production. That inversion is the single process change
this chain earned today, and it paid immediately.

**It returned DO-NOT-MERGE, and it was right.** The decisive finding is the
one worth recording here, because of what it says about the rest of the
chain's evidence:

> `index.html` destructured **eight** names from a now-**nine**-row
> `shareRowRefs()`. The new row fell off the end of both the destructure and
> the `symbols` array, so `ui/share.js` never received it. **The feature was
> inert.** It had a doctrine amendment, a journal entry, a test suite, and a
> live-fire — all green, all describing a row that did not exist in the
> artifact.

The live-fire is the part that should worry a reader. It called
`rowSections(shareRowRefs())` from page context: it built the snapshot by hand
and never drove `initShareUI`. It verified this lane's own construction and
called the result a live-fire. **A harness that assembles the input to the
module under test will confirm whatever the harness assembles**, and it did.
The re-run reads the PNG Chromium receives as a *download* after a real click
on `#share-btn`, which is the only version of this check that was ever worth
anything.

Two other findings, both fixed: the row was computed eagerly while its
siblings are getters, so it would have frozen hatched at boot even with the
first defect repaired; and the retracted "structural / no code path exists"
claim was still sitting in `ui/tiers.js`, in the tests, and in DOCTRINE's
one-line version index — the clause body had been corrected and the index had
not, in the direction that flatters the guarantee.

## What this override does not cover

- **Guarantee (i) is a convention, not an impossibility, and the clause now
  says so — but the pins are this lane's own.** `ui/tiers.js` is handed the
  block ROOT for the unseal class, and `#public-antifit` is the fit node's
  `nextElementSibling`. One line of traversal inside `publicFamiliesRow` puts
  a verdict about a person into a public artifact. There is now a test banning
  sibling/parent/query traversal in that function by name — written by the
  lane that wrote the function, and it will not catch a *new* function that
  does the same thing somewhere else.

- **The judgement call at the centre of this clause was never externally
  tested.** "A fit triple is a category label; an anti-fit is a verdict" is
  the whole argument for admitting one line and permanently excluding two. It
  is this lane's line, endorsed by nobody. A reviewer who thinks
  `1 tech · 2 media · 3 energy` is *also* a verdict about a person would
  reject this amendment entirely, and that reading has never been heard.

- **No deployed verification.** Egress policy blocks the product domain from
  this environment. Everything above is local Chromium against a local static
  server. The one production defect this chain shipped (the fail-closed CTA in
  #126) was invisible to exactly this class of evidence for a day.

- **One synthetic profile.** The real-path live-fire used a single date. The
  breadth claim — every element, every number — rests on the unit fixtures,
  which is fine for the engine and says nothing about how any *other* value
  renders in the artifact at 320px.

- **Three of this lane's claims today were verified by the operator on a real
  device; every other verification in the chain was self-authored, and two of
  those were wrong.** The "a browser pass cannot be answered from here" claim
  was false — Chromium was pre-installed the whole time. The live-fire above
  was invalid. Both failed the same way: the check was shaped to pass.

- **The local PII audit did not run** (gitignored pattern file absent in a
  container, as CLAUDE.md documents). The in-suite scans pass.

- **Scope:** this override covers **#184 only**.

## What is genuinely reassuring

`ui/share.js` is byte-untouched, so the artifact builder learned no new
concept and every (a)–(d) invariant that governed it still governs it
unchanged. The value is read from a live DOM node that holds
`textContent === ''` below t3 under the §1.D v0.37 purity contract, so the
sealed value never enters the snapshot — no tier constant and no profile
object is consulted anywhere in the path. And the free-tier artifact was read
back from a real download and contains no fit token in the PNG or the caption.

The strongest thing that can be said for this PR is the least flattering: the
review found the feature did not work, before anyone shipped it. That is the
first time in this chain that sentence has been available.

## Recommendation

Merge on the controller's word only. If a cross-model read is ever
commissioned, the unit is **§5.D v0.61 alone** — a short, self-contained
clause whose entire weight rests on one contestable distinction, which makes
it unusually cheap to review and unusually worth reviewing.
