# L48 override — PR #173, the correction PR

This file is the L48 sighting log by construction. **Sighting #18**, and the
smallest-stakes one in the chain: no behaviour changes, no doctrine changes,
no content changes. One comment, one `CLAUDE.md` recipe, one
correction-on-sighting, one journal entry.

## The change

- **PR:** #173 — records that local live-fire IS available in this container
  (Chromium + Playwright pre-installed), corrects the claim that it was not,
  documents the recipe in `CLAUDE.md`, and folds in the stale
  `?paid=t1|t2|t3` comment above `handlePaidReturn`.

- **Why it needed an artifact at all.** It is not docs-only: `ui/payments.js`
  is a `.js` file, so the gate's exemption does not apply even though the only
  edit inside it is a comment. That is the gate working as designed — a
  predicate that exempted "comment-only" changes would need to parse
  JavaScript, and the failure mode of getting that wrong is worse than the
  cost of this file. **Noticed before merging rather than after a red check**,
  which is the one process detail in this chain worth being pleased about.

- **State at this writing:** suite **45 files / 1580 tests** green — the same
  count with and without this change. `package.json` byte-untouched; the
  browser driver used for the live-fire pass was installed under `/tmp`, never
  in the repo, so §7 stage 4 is unaffected.

## Who reviewed

**One author, no reviewer** — sixth consecutive. This lane made the false

clearance.

## What this override does not cover

- **The correction is this lane grading its own homework.** The claim
  corrected here ("a browser pass cannot be answered from here") was written
  by this lane across four documents and repeated to the controller several
  times. Nobody else caught it; it surfaced only when the controller asked for
  a test that forced the attempt. **The general failure — a true limitation
  (the deployed domain is unreachable) laundered into a false one (no browser
  is possible) — is not fixed by this PR.** A recipe in `CLAUDE.md` makes the
  specific instance harder to repeat; nothing here makes the pattern harder.

- **The live-fire evidence is not in the repo and cannot be checked by a
  reader.** Four screenshots and a JSON probe report were produced under
  `/tmp` and are described in the journal entry, not committed — they carry a
  rendered specimen sheet and belong in no tracked file. So the entry's
  live-fire claims rest on this lane's report of what it saw, exactly the
  epistemic position the entry criticises elsewhere. A reviewer who wants to
  check them must re-run the recipe.

- **The `CLAUDE.md` recipe is untested by CI.** Nothing in the suite executes
  it, so it can rot the way the `?paid=t1|t2|t3` comment rotted — the very
  defect this PR fixes. It carries a live version-pinned path
  (`/opt/pw-browsers/chromium-*/chrome-linux/chrome`) that will break silently
  when the container image changes, and no test will notice.

- **The comment fix is unverifiable by the suite** for the same reason every
  comment is. It is correct today; nothing pins it.

- **The local PII audit did not run.** In-suite CI scan passes.

- **Scope:** this override covers **#173 only**.

## What is genuinely reassuring

No behaviour moved, so the blast radius is documentation accuracy. The suite
count was **counted rather than recalled** before being written down, which is
the discipline whose absence produced two of this chain's defects. And the
live-fire pass it records independently corroborated the controller's own
check of F1 — two instruments, same answer.

## Recommendation

The `CLAUDE.md` recipe is the part worth a second opinion, and the question
is narrow: is a version-pinned browser path in an instruction file a
maintenance liability worth taking on, given nothing tests it? An alternative
is a glob or a documented "find the chromium under `$PLAYWRIGHT_BROWSERS_PATH`"
instruction. This lane chose the concrete path because a recipe that requires
improvisation is a recipe nobody runs — but that is a judgement call, made by
the lane that just demonstrated it will not attempt something it believes
impossible.
