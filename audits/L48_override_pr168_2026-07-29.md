# L48 override — PR #168, closing the objection this lane raised itself

This file is the L48 sighting log by construction. **Sighting #17**, and the
fourth `DOCTRINE.md` change in this chain cleared without a cross-model read.

## The change

- **PR:** #168 — the t4 mode driver moves off the free surface. The mode of
  work was keyed by the **life path** (free since §1.D v0.38); it is now keyed
  by the **birthday** number (t2). New §1.D v0.59 amendment, doctrine footer
  → v0.59. `content/public.v2.js` is new; `content/public.v1.js` is
  byte-untouched per §4.

- **What it changes for a buyer: nothing, because there are none.**
  `T4_PRODUCT_URL` is still empty and the rung unbuyable, so no purchase has
  ever rendered a t4 block. That is the single most important fact about the
  timing of this fix and it is the reason it was worth doing now.

- **State at this writing:** suite **45 files / 1578 tests** green in a clean
  checkout. Rebased on `origin/main` @ `f2ac204`.

## Who reviewed

**One author, no reviewer** — for the fourth doctrine change running. This
lane wrote the objection, the amendment that closes it, the new content file,
the tests, the journal entry and this clearance.

There is one honest mitigation and it is worth stating precisely because it is
easy to overstate: **the objection being closed here came from this lane's own
adversarial process** — it was written into `PUBLIC_TIER_SPEC.md` §6.1 before
the rung shipped, repeated in the #153 PR body and in sighting #15, and
independently re-derived by the post-merge cross-read as its most likely
finding. That is a lane arguing with itself in public and losing, which is
better than a lane not arguing. It is **not** a second reader.

## What this override does not cover

- **The replacement was chosen by the same lane that chose the original.**
  The birthday is defensible on three mechanical grounds and one substantive
  one (§1.G already calls it "the recurring skill"). But nobody outside this
  lane has agreed that a **day of the month** is a good basis for a mode of
  work — and the honest counter-argument is available: it is a coarser,
  more arbitrary number than the life path, and its apparent aptness rests on
  a role label from this project's own meaning registry rather than on the
  numerological tradition it cites.

- **The deeper question is untouched.** §6.1 asked whether re-reading
  coordinates against fixed tables is a thing to *sell*. This PR answers only
  the narrow form of it — the driver is no longer free-surface. Whether the
  t4 read is worth $9 at all is unexamined, and no reader outside this lane
  has been asked.

- **A doctrine amendment now records a design decision no one has audited**,
  and this is the fourth such clause in one day (v0.58, v0.59 in §1.D; the
  L48 sightings #15, #16, #17). The constitution is accumulating solo-authored
  clauses faster than anything is reading them.

- **The `lifePath` → `birthday` field rename inside the mode table** is a
  content change made in a new file, which is the §4-correct mechanism. It is
  also the second time in this chain a field has been renamed because it
  named the wrong thing. A third would be a pattern worth stopping on.

- **The local PII audit did not run**; the in-suite CI scan passes. No browser
  pass — though the block's shape is unchanged and only its content differs,
  so §8 gate 9 has less to say here than it did for #157.

- **Scope:** this override covers **#168 only**.

## What is genuinely reassuring

The authored table carried over **unedited** — themes, registers, methods and
character priorities are byte-identical to v1, so this change cannot have
smuggled copy through as a mechanical edit. The immutable v1 file is
untouched and still imported. The rollback is a revert with no migration. And
the fix landed while the rung was unbuyable: had the Gumroad product been
created first, the same correction would have silently changed what someone
had already paid for.

## Recommendation

If any single thing in this chain gets a cross-model read, it should be the
**pair** §1.D v0.58 + v0.59 read together — a rung and its own correction,
authored by one lane a few hours apart, with a price in the constitution that
still contradicts the column above it. Reading either alone will miss that.
