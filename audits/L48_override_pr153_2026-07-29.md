## What this override does not cover

The fail-closed design bounds the commercial damage. It does not bound the
judgement.

- **A price was set by an implementer.** §1.D v0.55 superseded the Price
  column to $1 / $2 / $3. This clause adds a rung at **$9** because the
  commissioning brief said $9, and **no tracked file records that ladder**.
  The amendment states plainly that it does not adopt the radius framing and
  takes no position on re-pricing t1–t3 — but a price now sits in the
  constitution on one lane's authority, and the two ladders still contradict
  each other in the same document.

- **The rung sells a re-reading of coordinates the free sheet already
  shows.** The mode driver is the life path — free-surface since §1.D v0.38.
  Nothing in the t4 read is new information. That was an open design question
  before this PR (spec §6.1) and it is an open design question after it, with
  the difference that it is now behind a price. **This is the finding a
  reviewer is most likely to reach, and it was reached by this lane, before
  merge, and shipped anyway on instruction.**

- **The doctrine amendment cites its own limits, which is not the same as
  clearing them.** §1.D v0.58 names the life-path driver, the month-branch
  strength model, and the absent cross-model read. Naming a limit inside the
  clause that creates it is a weaker instrument than review, and this file
  should not be read as claiming otherwise.

- **No live-fire pass.** §8 gate 9 wants an operator-run deploy-preview pass
  for a release touching `index.html`. This touches it — new markup, new CSS,
  new boot wiring. The block's sealed and unsealed rendering has been tested
  against a hand-rolled DOM, never against a browser. Phase 2F-1 is the
  precedent for why that matters.

- **The local PII audit did not run.** It needs `audits/local_personal_data.txt`,
  gitignored and absent in a fresh container. The in-suite CI scan passes.

- **Four existing test pins were rewritten by the author of the change they
  were guarding.** The ladder pins, the seal count, and the engine's
  surface-isolation assertion. Each rewrite is argued in the diff and each
  kept or tightened its neighbouring invariant (cell count still 14; the
  isolation test now names `ui/public.js` as the only importer rather than
  dropping). That is the right shape — but a guard rewritten by the code it
  guards wants an outside reader, and did not get one.

- **Scope:** this override covers **#153 only**.

## What is genuinely reassuring, so the balance is honest

The append cannot reach an existing owner: every rung keeps its rank, the
stored tier keeps its meaning, and the R2 legacy grandfather is deliberately
frozen at `t3` with a test that fails if a future rung widens it. The rollback
is a revert with no migration, because no device can hold a tier nobody can
buy. And the commercial surface fails closed rather than half-open — the
failure mode of a half-wired paywall is a dead checkout link, and that one is
structurally impossible here.
